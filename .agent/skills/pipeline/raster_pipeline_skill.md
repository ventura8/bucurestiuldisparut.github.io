# Raster Pipeline Skill

The Python + GDAL pipeline that turns declassified USGS film scans (Corona KH-4, Argon KH-5, KH-7, KH-9) into georeferenced historical layers. Package `pipeline/src/hcm_pipeline`, run as a Cloud Run Job: scaffolded in M0 (configuration, logging, the M2M client, the doctor step, the fakes and the synthetic world in `pipeline/tests`), every processing step built in M3 under `docs/research/M3-interfaces.md` (§2.3 who writes which job field, §4 the job model, §5 the steps and CR-M3-19 as built, §6 the georeferencing conventions); the golden documents it writes are in `pipeline/tests/contracts/`, and `written-documents.json` holds one document of each shape its real writers produce (`tests/integration/test_written_documents.py`, finding 62). What waits for the real cloud: `docs/research/M3-status.md`. Plan: `docs/research/PLAN.md` → *Raster pipeline*; tests: `docs/research/design-review-testability.md` §3.6; reliability: `docs/research/design-review-security-cost.md` §4.

## Toolchain

- `osgeo.gdal` from the pinned `ghcr.io/osgeo/gdal:ubuntu-small-3.13.3` image (by digest). That image ships **Python 3.14**, so `requires-python = ">=3.14,<3.15"`. Never pip-install GDAL and never use rasterio wheels (they bundle a second GDAL into the same process).
- Poetry 2.5.1 (its own venv, `pipeline/requirements-poetry.txt`) and the project `pipeline/pyproject.toml` with `poetry.lock`; the venv uses `--system-site-packages` so `osgeo` is visible, and `--without-pip` (the seeded pip had advisories). numpy and opencv-headless for image work.
- `pipeline/Dockerfile` (build context `pipeline/`) stages: `base` (GDAL image), `deps` (Poetry, locked runtime dependencies in `/opt/venv`), `test` (adds the dev group and the tests; its command runs pytest), `runtime` (uid 10001, the venv and the package only; default command `doctor`). The runtime image keeps GDAL's tcmalloc preload; only the quality image clears it.
- GDAL is imported only through `hcm_pipeline.raster` (exceptions enabled). Exit codes (`hcm_pipeline.exit_codes.ExitCode`): 0 done or waiting, 1 failed, 2 usage, 3 configuration.
- Lint like every Python here: ruff (complexity 5), mypy strict with stubs for the GDAL API we use in `pipeline/typings/osgeo/`, radon grade A (complexity and maintainability, over `pipeline/tests` too: a long test file grows past A, so split it by behaviour; lesson 573), bandit; logging through the pipeline's logger with secret and signed-URL redaction, never `print`.

## Steps (short, idempotent, resumable)

1. `fetch`: M2M with the deterministic label `hcm-{job}`, a resumable stream into GCS (`pipeline/usgs_m2m_skill.md`); transfer size is the larger of `download-options` and Content-Length (Landsat Product Bundle by name; lesson 702), a dropped connection resumes from the bytes held (lesson 705); the image's `__version__` is the installer's `HCM_RELEASE` build arg (lesson 704); `extract` keeps only the TIFF segments; `stitch` mosaics them and crops the film border.
2. `inspect` (uploads): GDAL decides whether an upload carries its own georeference. Only here is a GDAL failure `apiError.imagery.unreadableRaster` ("check the file and upload it again"); every other step's is `apiError.imagery.processingFailed` (`gdal_step`'s `code`, CR-M3-47: an admin is never told to re-upload a USGS frame).
3. `locate`: the corner guess (the frame's rotation and mirror among the square-pixel ones of eight, a camera with a half angle through its panoramic model and on its exposure alone, scored against Sentinel-2; under 0.2 searched around a window widened by half with masked gradients, whose ratio and z can accept it: findings 62–63, DECISIONS §84, lesson 361), the city window plus 10 %, a crop no side of which exceeds `MAX_SCAN_PIXELS`, four corner GCPs. A guess nothing accepts is weak, no failure: the union of every orientation that reaches the window with a 10 km margin, never cut, the delivery kept, its corners cleared when the scan waits for points (`weakCorners`). `apiError.imagery.cityNotFound` only for a frame that reaches the window under no orientation.
4. `reference`: Sentinel-2 L2A from a public STAC and OSM features from Overpass, cached in the private bucket. **The reference is OSM data plus open Sentinel-2, never Mapbox Satellite** (Mapbox terms). The Sentinel-2 date is the least cloudy of up to 5 clear covering sets that agrees with the others within 7.5 m (`agreement.py`, M15 *The reference guard*, lesson 464); the verdict is `reference.s2Check`.
5. `georef`: automatic GCPs (M3: CLAHE, SIFT and correlation over three levels, RANSAC, at most two pairs per cell, leave-one-out checkpoint RMSE; M4, `docs/research/M4-interfaces.md` §2: ORB when SIFT finds fewer than 200 keypoints, OpenStreetMap's lines as a second channel matched tile by tile against OSM's proximity field, RANSAC across both, a confidence and a residual per pair, a fifth held out as checkpoints from 15 confident pairs); pairs from 0.6 join the fit, lower ones are the version's `suggestions` for the georeferencer; too few pairs → the job waits for the admin's points (`awaiting_gcps`). The admin's live `fitTransform` and this package's `transforms.fit` share the golden cases; a poly2 inverse is fitted on a 15×15 forward grid (`INVERSE_GRID` / `POLY2_INVERSE_GRID`), never on the pairs alone (DECISIONS §144, lesson 553).
6. `warp`: `-tps` through what the version's map is (`rendered_points`: a spline's own points, an affine or poly2 fit sampled on 17 x 17 nodes, a stored `georef.lattice`; never `-order N`, whose reverse polynomial is not the fit: M15 §1) to EPSG:3857 on the zoom grid (KH-4 z15, KH-4A/B z16, KH-9 panoramic and KH-7 z17, KH-9 mapping z15), `-cutline` for a crop.
7. `export`: the preview, and only for a city with `imagery.publishThroughMapbox` an 8-bit COG and a 300 MB or smaller GeoTIFF for the free Studio path; `pyramid` (M12, `docs/research/M12-own-tiles.md`): 256 px WebP tiles packed into `tiles.pmtiles`, with `thumb.webp`, recorded as `output.tiles`, read through `rgba_view`, whose alpha loses the film's dark rim and its fade (`tiles/rim.py`: the black core the transparent outside reaches, then the fade grown from it while darker than 65 % of the scene's own median, at most 150 ground metres from the alpha's edge; written once as `rgba-alpha.tif` with the source's overview levels, so the view keeps the COG's overviews; never move the stitch crop for it, lessons 497 and 499); a proved frame also gets `align.tif`, what later frames' film ties are measured against (M15, *Joint solve*); `register` writes the layer version for approval. The job `layer-tiles` runs `pyramid` alone from an old version's `cog.tif`: it is a side job (`SIDE_JOB_TYPES`), so it ends `succeeded` and never moves its version. Tiles are recorded only at the version's own `rasters/C/L/V/tiles.pmtiles` and `thumb.webp` (`isOwnTiles`; `worker.step` refuses any other path, and a side job's change to any other output field); publishing moves the archive to the public bucket (lessons 405–410). `gdal raster tile` through `gdal.Run`: pass `ctx.flags.gdal_progress`, and do not read a tile's band count as its alpha: GDAL writes a tile with nothing transparent as three bands (`docs/LESSONS.md` 394).
8. Publishing is functions' `imagery.publish`: only after approval, or automatically when the checkpoint RMSE, on checks held out of the fit (M9), is under the city's threshold and a USGS frame covers 90 % of the city, and only within the compute-unit guard (`pipeline/mapbox_publishing_skill.md`).
9. `layer-join` (M8, `docs/research/M8-join-interfaces.md` §3, §13; queued only by `imagery.join`): `align`, `merge`, then `export` and `register` unchanged, as `merge` writes the same `warped.tif`. Code in `hcm_pipeline/join/` (`canvas`, `seams`, `measure`, `correction`, `tone`, `compose`, `plan`, `warping`) and `steps/{align,merge}.py`; every threshold a named constant, calibrated on synthetic scenes until rehearsal D3. `align` writes `join-plan.json` and `join-owner.tif`, so a retry does not re-measure. It reads each frame's `scan.tif` and GCPs and resamples once; a COG is never an input. Thresholds are ground metres (`ground_scale`). A seam the correction did not help is refused: `applied:false`, `afterRmseM` = `beforeRmseM`, no nodes, and the others judged again. A search must reach past what it reports (`docs/LESSONS.md` 365). A warp runs on GDAL's reverse transform, so a node is a place and the pixel `reverse` reads there, a thin-plate part keeps its own points as nodes, and a transform is tested through a real warp on a non-affine frame (`docs/LESSONS.md` 366). **A join closes the gap; absolute error stays the worst frame's own.**

## M9: a frame found and proved anywhere (`docs/research/M9-calibration.md`)

- `locate` finds the frame with no landmark (`calibrate/`: votes, dense tiles, the proof's gates, pairs), or takes a bounded crop and waits for a few rough points. A local matcher plugs in behind `calibrate/ports.py` only: never a cloud model, and its output is only a proposal (M10, below).
- A Corona strip (`SensorSpec.strip`: KH-4, KH-4A, KH-4B, a film 4:1 or longer) is searched window by window (`calibrate/strip.py`, M9 §16): the city plus 15 km along the strip where the footprint puts it under each orientation, a map linear along the footprint's long edges, the chain unchanged inside; a footprint off the city slides 40 km windows (no local AI). A frame nothing proved keeps no window (lesson 607, M9 §17): a strip's window, a search out of time or a frame over `WHOLE_MAX_PX` makes `scan.tif` the **whole exposure shrunk** (`steps/whole.py`, marked in the file's own metadata `HCM_WHOLE_FRAME`, no corner pairs), which waits for the owner's rough points; `georef` then cuts the film around them at full resolution out of the segments and moves the points into the crop (`steps/recrop.py`). Only a small frame searched whole and in time keeps `bounded_crop` and the matcher.
- **Locate again** (`functions/src/imagery/locate-again.ts`, S-A69-*): a frame waiting for points goes back to `queued` from `stitch`, `fetch` and `extract` as recorded, `JobDoc.filesOn` (a job moved after it parked) refused with `locateFilesElsewhere`, and `imagery.saveGcps` always leaves the points one attempt (the runner's `_finished` and `_consumed` decide, unchanged). A new field `locate` writes on the version must also be forgotten there, or a second search shows the first's. It is no import: `refuseNewRasterJob` is not asked. M18 (`docs/research/M18-improvements.md` §3): it also takes a frame whose job failed at `stitch` or `locate`, gives a parked frame's search a run of its own (`attemptForSearch`) while a failed crop's runs count (`requireRunsLeft`: `attemptsExhausted` at `JOB_MAX_ATTEMPTS`, or the same failure repeats without end), and `imagery.tick`'s `relocate` part (`functions/src/imagery/relocate.ts`) asks it by itself once a frame's `JobDoc.searchedWith` differs from the image the Cloud Run job runs (only `from === 'job'`: the record lags, and each switch of source would re-run every parked frame), unless the job's `placingPoints` mark (the georeferencer's, `packages/admin/src/georef/placing.ts`) is younger than `PLACING_POINTS_HOLD_MS`; `requeueIn` drops `searchedWith` and `placingPoints`, or a frame would search again at every tick. The day's limit counts only `usgs-import`, `geotiff-import` and `layer-join` (`COUNTED` in `limits.ts`); a re-run (`regeoref`) asks only `refuseWhileGuardRed`.
- **Retry past the cap** (`retryPastCap`, `retryCures` of `@hcm/shared`, used by `jobRetryable` and `imagery.retry`): the owner's Retry of a run on their own computer (`runOn: 'local'`, `localOnly`, `archive-series`) passes `JOB_MAX_ATTEMPTS` (its `attemptsExhausted` included) and sets `attempt` to 0; a cloud run and every publish keep their caps, and automatic retries never pass them. A new cost cap goes through these two predicates, never a copy on one side (`docs/LESSONS.md` 574; S-A12-HAPPY-LOCAL-RETRY-PAST-CAP).
- What a run writes: `calibration` (`calibrationSchema`, `packages/shared/src/schemas/imagery-calibration.ts`), `georef.checkpointKind`, `output.coveragePct` (at most 100). A new field lands with its schema, then `HCM_WRITE_CONTRACTS=1` regenerates `written-documents.json` (`docs/LESSONS.md` 370).
- What reads them: `functions/src/imagery/approval.ts` (only the proof's own fit publishes itself: `method: 'auto'`, `held-out` checks, a proof on record, no check dropped, `measuredPct` at 70, and, for a USGS frame, 90 % of the city), `join-plan.ts` (a measured outline, the proof's or `output.outline` off the render's alpha, beats the estimate: a USGS render's `bounds` are the whole window), `pass-calibration.ts` (`imageryPasses/{key}`, the next frame's first place to look; `worker.step` reads it, the rules allow no client).
- A figure that decides anything is held out before the RANSAC; a real frame that refuses is looked at before a gate moves (`docs/LESSONS.md` 371, 372). A gate over survivors says nothing of what left: `calibrate/rival.py` looks once more with the search open (374). Ranges are ground metres, never a share of the window; a sensor's warps each ask `VOTE_WARP_MIN_TILES` (376); a place may lie over longitude 180 or across two orbit tracks (377). Judge a change of the map on a ruler no fit saw, film against film first (`tools/acc-ruler.py`, M9 §14 *The measuring stick*; `docs/LESSONS.md` 456); bound what a better reference could buy before fetching one (M9 §14 *Reference variants*; 457): a tile against Sentinel-2 holds 10 to 14 m of noise. Read a warp through GDAL's own reverse, which `-order 2` makes apart from the fit (10 m on half the frames, 458); `align` measures seams only within one pass, and a pair fitted together in poly3 reads better than any frame alone (M9 §14 *Frames together*). A matcher is judged on that ruler, never on its own tiles, its gate set on a wrong-place null: gradient orientation is the one change that helps (M9 §14 *Matching variants*; 459). M15 (`docs/research/M15-calibration-accuracy.md`, *As built*): a KH-9 pan frame's map is its camera (`calibrate/camera.py`), fitted on every tile and stored as `georef.lattice`, which only the warp reads; a change of the map is read through the product's own functions and GDAL's transformer on the folds of `tools/acc-transforms.py` (`m15b-product.py`), and a guard is set from counts, never from the figure (460). Two cameras mirrored about the nadir hold the same tiles: both signs are followed and the plainest is kept (`plainest`, 462); carrying the second-order term on its tangent beyond the tiles, or falling back to poly2 there, read far worse on the ruler's edges and is not built. A research harness on Python 3.14 runs its pool by `forkserver`: workers import the script again, so its output folder and any patch are set at module level, or a worker writes over the stored runs (M15 *Review of 2026-11-08*). A proved frame is joined to the accepted proved frames it overlaps, which stay still (`calibrate/joint.py`, `joining.py`, `ties.py`, `steps/aligning.py`; M15 *Joint solve*): film ties measured on each one's `align.tif` (5 m, kept by `export`), nine times a tile's weight; a partner over 6 m from the rest leaves first and alone (465); a version that cannot be read (the server answers null for one that fails its schema and counts the ones its list left out; any `WorkerApiError` on one read) is no partner and never fails the frame, and nor does a partner whose `align.tif` cannot be looked up, staged, read or measured (`PARTNER_FAILURES`, one line naming it; `RunStoppedError` still stops the run): a loop over others' documents and files catches per item at every step, not only the first, and an adapter maps its client library's errors (httpx, google.api_core) to the port's own (481, 482, 483); no chain (a frame of the admin's points is never held); a cubic is restricted to the film's measured box. Judge it with the frames joining in import order and the held blocks out of every tie too (`tools/m15e-joint.py`). A KH-9 pan frame over relief its camera shows is fitted over the city's Copernicus DEM GLO-30 (M15 *Terrain*, `calibrate/terrain.py`, `surface.py`, `steps/relief.py`, `georef/rpc.py`): rows fitted on the places the film shows them (height times the camera's view tan), the map back to the ground through the heights, which the frame carries (`georef.terrain.heights`, `georef/heights.py`); every reader shows that map through its RPC over those heights (the warp, a join's part and the next frame's ties through `steps/warp.py` `attached`, the georeferencer through `terrainTransform`), never through a lattice of it (a 17 x 17 lattice loses metres of it; the flat one lay 8 to 15 m off, 467). Under 1 m of relief beyond a second-order fit once scaled by what its tiles show (469), or without a camera, or without every surface tile readable (468), the frame is fitted flat, exactly as before. Judge it on the same ruler with the RPC read through GDAL's own transformer (`tools/m15f-terrain.py`, `acc2/ruler.py` on the NUC), per frame by the three-cornered hat, never by the RMS of its own pairs (which credits it its partners' gains), and against OSM rails: a frame that is not corrected can read worse when it shares an error with frames that are (KH-7, A038, F006).

- Other cameras (M9 §14, one real frame each): a KH-7 strip lies as a parallelogram, so its warps carry `SearchRange.shears_deg`; KH-9 mapping needed nothing; a KH-5 Argon frame (140 m) refuses and waits for points. A real frame that gets no vote: look at its preview first, prove from a hand start, then put the true affine under the votes, to learn which dimension the search lacks before widening it. No real Corona has run.

## M10: the local matcher (`docs/research/M10-local-ai.md`)

- ALIKED + LightGlue at 15 m a pixel, **on the owner's computer only, in a sidecar with no network**; graphics card first, the processor only with its reason in the log. `pipeline/src/hcm_pipeline/matcher/` runs under the image's **Python 3.12** and imports no `hcm_pipeline`: no `except A, B:`, no forward reference in an annotation (`docs/LESSONS.md` 379). `worker/local_matcher.py` and `worker/ai_files.py` are the worker's half; `calibrate/ports.py` the port; Cloud Run keeps `NullProposalMatcher`.
- A proposal is only a proposal: `chain.py` proves it over at least `MATCHER_PROOF_SIDE_GROUND_M` (30 km) under the same gates, and `support` reaches `calibration.proposer`, for display, never a gate or `Found.votes`.
- The request starts each orientation at **each** of the sensor's scales (`starts_each`), the model's own first; the processor looks at two orientations, each at every scale. A change to `SearchRange.scales` moves what the matcher looks at: rehearse a real frame again (`docs/LESSONS.md` 380, `docs/research/M10-local-ai.md` *The whole chain on a real frame*).
- **Each failure ends at the admin's points with a log line, never a failed job:** raise `StandAsideError` with a word `WORKER_AI_WHYS` holds; `propose` turns any other fault into one too, and only `RunStoppedError` passes (`_stand_aside_of`). A lost request keeps what was already proposed. A silent processor run must stay impossible: `HCM_AI_DEVICE=gpu` that finds no card exits 77, `cpu` without `HCM_AI_WHY` is refused.
- The sidecar lives **only while `/state` says `wanted`**: `LocalMatcher.propose` must leave `wanted` false however it ends, and the starter must never block on the sidecar: its loop is what sees a new image and removes a hung sidecar (`docs/LESSONS.md` 383).
- **What the starters may hold under Windows PowerShell 5.1** (`docs/LESSONS.md` 382): no `\"`, no empty argument to a native command, no quote inside one (`functions/test/worker/starter-windows.test.ts`). `pwsh` on a machine that has it parses the part after `#PS-BEGIN`; the gates do not.
- A proof over more ground than the window speaks for the window only through `Found.window_spread`: a new figure read from a wide proof goes through it too.
- Tests take no card and no weights: `tests/fakes/sidecar.py` (the real search over ORB keypoints), a fake `torch` (`test_matcher_torch.py`), stand-ins of `docker` and `curl` (`functions/test/worker/starter-sidecar.test.ts`). A new upstream file goes in `pins.json` with its hash, on `AI_FILE_HOSTS`, its licence read into `matcher/NOTICE.md`; LightGlue's `superpoint.py` is confidential and never leaves the tarball.

## M20: a local archive (`docs/research/M20-import-local.md`)

- The worker's own page (`GET /import`, `worker/import_page.py`, `worker/imports.py`) takes a folder or a zip over loopback into `<work>/import/<archiveId>/x/` (`archive/intake.py`); the zip is read in place under `archive/zipread.py`'s limits (100,000 entries, 200:1, 64 GiB, the free space less 10 GiB); every path goes through `archive/safepath.py`.
- `archive/probe.py` hashes and sniffs (`archive/magic.py`); a raster or a PDF is read by the spawned `probe_child` with `RLIMIT_AS` 4 GiB and 60 s of CPU; a crash or timeout is an `unreadable` row. `archive/classify.py` puts each file in one series or one skip reason; `archive/grammar.py` reads sheet names; `archive/sidecar.py` reads the owner's `hcm-archive.json` (data, entry by entry; every matching entry merges from the root down, a deeper key overriding: lesson 530); `archive/rights.py` pre-flags §7; `archive/report.py` builds `worker.archiveReport`'s body in the ladder's order (§1.7) with stable series ids.
- The job `archive-series` (local-only, counted once per series; `daily` waits are released by `imagery.tick`): `steps/gather.py`, `steps/place.py` (`PLACERS`, `wait_for_help`), then `export` (a line-art COG is DEFLATE), `pyramid` (`series_encoding`, `tiles/encoding.py`), `register` and the publish steps. A placer writes `warped.tif` and the version's `archive` report; the approval reads that report under the map threshold (§5). **Line art: nearest at every zoom including overviews** (`overview_resampling`; lesson 546 / DECISIONS §145 — averaged RGBA made Post 1847 almost invisible; `S-P20-BAD-LINEART-AVERAGE`). Params are `archiveSeriesParamsSchema` / `_ARCHIVE_SERIES_KEYS` (strict): optional `restitch` (boolean) only here, for Locate again on an overview mosaic with pieces left out (`placing/restitch.py`, DECISIONS §216e/g, lesson 701); a new key a callable writes must land in both twins or `params_of` fails the job on start.
- The placers (`placing/`, as built §15): `embedded` (own tags, or a world file read by the placer itself: the pipeline's GDAL never lists a folder, lesson 522), `grid` (names to cells by `gridscheme`, frames, the quarter order from the seams, one rigid solve of the whole mosaic, every sheet rendered by `render`; a wait that does not prove prefers an archive overview mosaic as the stitched picture, three-band for a `colour` series), `single` / `atlas` / `pieces` (`maps.py`; `assemble.py` lays out pages by their edges and chains pieces by SIFT affines; `overview_find.py` lays pieces on a complete smaller-scale overview beside the tiles when one matches, fitted on grey features but pasted in three bands for a `colour` series (lesson 572), else today's joins; a published overview mosaic with pieces left out is laid on again by Locate again (`restitch` → `placing/restitch.py`); `pdfpages.py` takes PDF page images out with pikepdf). A drawn map: `streets` (paper corridors, crossing-number junctions, lesson 525), `coarse` (chamfer, three far-apart candidates), `fine` (junction pairs, RANSAC keeping the pixel flip, lesson 523; checks held out in blocks, `checks`), the winner by agreeing pairs and its rival at most half as many (lesson 524). The reference is the ladder's layers then OpenStreetMap, asked once per city window and cached in the work folder; never Mapbox Satellite. A placement that does not hold waits with `help` and `junctions` suggestions, never `failed`.
- The admin's side (as built §16): Imagery → Upload → Import local files links to the worker's `/import?lat=` page; the scan's report opens by itself in the admin (`#/imagery/archive/<id>`), one Import makes the jobs, and each series' progress reads its version and job. The owner's `hcm-archive.json` is read at the archive's root or in its one top folder (a folder chosen whole), its paths relative to the root. A new job type the pipeline runs joins every hand-kept list of them (the worker feed's `PIPELINE_TYPES`, lesson 529).

## Job state machine (`cities/{c}/jobs/{id}`)

- Leases and heartbeat; `waiting_usgs` with backoff for maintenance (503 HTML); re-login at 100 minutes; a cancel flag; SIGTERM → `cancelled` with temp files removed.
- The task **exits while it waits** on something outside us (USGS preparing, maintenance, a rate limit, the admin's points): it releases its lease and exits 0; `imagery.tick` (every 15 min since 2026-11-12; a run that ends dispatches the queued jobs at once) resumes it, re-dispatches a lost or out-of-memory run and polls MTS. A second execution of the same job finds the lease held and exits 0 untouched; SIGTERM without a cancel requeues the job and keeps the download's checkpoint; a cancel deletes the job's `work/` objects (the dispatcher then releases the layer's pending version, the scene and any compute-unit reservation, CR-M3-18).
- Three Cloud Run jobs (`CLOUD_RUN_JOBS`, finding 56 of 2026-11-01): `raster-fetch` (1 CPU / 4 GiB) runs an import's download phase (`DOWNLOAD_STEPS`: fetch, extract) and ends the job `queued` with its lease released; the dispatcher then sends it to `raster-pipeline` (4 / 16) or `-xl` (8 / 32, a KH-9 panoramic frame) for the rest, in the same attempt. A run whose job names no machine walks every step (a local worker). The version records `machines.download` / `machines.process`.
- OOM → re-dispatch on the next larger job (`fetch` → `std` → `xl`; on `xl` the job fails); done steps never run again. Logs are redacted (signed USGS URLs never appear).
- `publish_scan` (`steps/common.py`) writes `scan-preview.jpg` (long side `SCAN_PREVIEW_MAX_PX`) and, for a scan longer than that, `scan-tiles.bin` (`SCAN_DETAIL_MAX_PX` long and `SCAN_DETAIL_MAX_PIXELS` in area, `detail_scale`, cut into JPEG tiles of `SCAN_TILE_PX` and packed in one object by `scan_tiles.py`; recorded as `scan.detailPath` / `scan.detailScale`): the georeferencer decodes only the tiles its pane shows once zoomed past the preview (DECISIONS-for-review.md §171 to §173). A picture a browser shows zoomed is never written as one JPEG longer than the preview. A new version file joins `VERSION_FILES` on both sides (`contract.py`, `imagery-paths.ts`, `enums.json`), or `worker.step` refuses the local worker's write.
- A frame is never held whole (finding 57, `docs/LESSONS.md` 329): `hcm_pipeline/frames.py` reads segments by windows and shrunk copies (`Segment`), `stitch` stages two at a time (`ctx.unstage`) and writes `frame.json` plus `frame-preview.tif`, `locate` scores the preview and reads the city's window from the covering segments; `GDAL_CACHEMAX` 1024 MB. A new raster step reads windows, and its test bounds the memory (tracemalloc) on a frame larger than the bound.
- The tick asks Cloud Run about a running job whose heartbeat is three beats late (finding 58): a killed run is failed with its reason within about 8 minutes; out of memory on `xl` is retryable.
- A long transfer reports its bytes with `ctx.report_bytes(received, total)`: `steps.<step>.bytes` and `totalBytes` with the progress, at most every 5 s (finding 55). The scratch folder is memory on Cloud Run: free a file once it is in the bucket.

## Tests (pytest, ≥ 90 % per file, inside the GDAL test image)

- **Synthetic georeferencing harness** (`pipeline/tests/synthetic/`): a seeded EPSG:3857 reference world (roads, river, parks, noise) served as a COG with HTTP Range behind a mock STAC item; a known ground-truth transform (projective plus panoramic term, optional rotation and mirror, upsample and blur, grain, an "urban change" patch); the scan made by inverse warp, split into overlapping segments, packed like USGS delivers, with metadata corners deliberately offset.

## Wiring into the repository (done in M0)

`pipeline/pyproject.toml` holds the Poetry project and the pipeline's pytest, coverage and mypy configuration; every command runs from the repository root, so `reports/coverage/pipeline.xml` and `reports/junit/pipeline.xml` carry repository-relative paths for Sonar and `scripts/ci/check_coverage.py`. `ruff.toml` already covers every Python file. The quality image carries Poetry (`/opt/hcm/poetry`) and the locked venv (`/opt/hcm/pipeline-venv`); the gates `pipeline-lock`, `pipeline-mypy`, `pipeline-radon`, `pipeline-bandit`, `pipeline-pip-audit` (static) and `pipeline-pytest` (tests) use them. Commands, layout and the re-lock recipe: `pipeline/README.md`; decisions: `docs/research/M0-handoff.md` → *Raster pipeline*.

- Memory budgets (lesson 608, `reports/resource-audit.md`): GDAL's cache and a warp's memory come from `rasters.gdal_memory` (a sixteenth and an eighth of what the process may use: the cgroup's limit and `MemAvailable`; `HCM_GDAL_CACHE_MB`, `HCM_WARP_MEMORY_MB` override), never a fixed number; `compose_canvas` warps each part into its own box and keeps the owners on their coarse grid; `gdal raster tile` gets `pyramid.tile_processes` (the cores but one, a quarter of the memory at 256 MB each); a crop is written by rows (`locate.write_crop`), a preview read shrunk from the file (`common.scan_preview`, `publish_scan` without pixels), an atlas's pages held grey (`assemble.Pages`, `compose_parts`). Minimum machine: 4 GB and 2 cores (M7, *The minimum machine*). A heavy call's budget is a test in a process of its own (`pipeline/tests/budget_probe.py`, `tests/integration/test_memory_budgets.py`): measure before and after on the NUC with the probe and put the budget between. A probe reads its own `VmHWM`, not `ru_maxrss`, which carries the parent's peak across `exec` (lesson 610).
- The worker on somebody's computer (lesson 609): the starters cap its container (`--memory` and `--memory-swap` at 60 % of Docker's memory, `--cpu-shares 256`; `HCM_WORKER_MEMORY`, `HCM_WORKER_THREADS`), the process nices itself (`worker/command.py`, `HCM_WORKER_NICE`) and GDAL takes the cores but one. An idle worker claims less often (`worker/pace.py`: `pollSeconds` for ten minutes after a job, a start or the admin's `GET /state`, then up to `worker.hello`'s `idlePollSeconds`, 60 s: a new job never waits longer); `WORKER_FRESH_SECONDS` (180 s) must stay above that longest wait with its jitter, and a server that names no `idlePollSeconds` is polled as before.
