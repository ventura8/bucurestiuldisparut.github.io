# Release v1.0.0 - The historic map engine, for every city

The first release of the **Historic City Map** engine, the viewer of București dispărut, for any city that wants its own historical map: old photographs placed on today's map, historical layers with a live opacity, swipe compare, Romanian and English, Material 3 on every screen. The full notes are in [docs/releases/v1.0.0.md](https://github.com/ventura8/bucurestiuldisparut.github.io/blob/v1.0.0/docs/releases/v1.0.0.md); the public contract is [docs/ENGINE_API.md](https://github.com/ventura8/bucurestiuldisparut.github.io/blob/v1.0.0/docs/ENGINE_API.md).

## Start a city

- **Static, no backend**: copy the starter kit (`templates/starter-kit/`: `index.html`, `city.json`, `README.md`), edit `city.json`, put your Mapbox public token in it and publish the folder on any static host, GitHub Pages included. Or run `npm create historic-city@1.0.0` to scaffold it.
- **With the admin, on your own Firebase project** (experimental until the admin's Setup runs there, CR-M5-7): `npx create-historic-city@1.0.0 self-host <folder> --project <id> --experimental`, then the admin's Setup Assistant.
- **From an existing city**: the admin's Export the city downloads a zip that serves it from any static host.
