# Historic City Map Maker v1.0.0-beta.1

The first beta of **Historic City Map Maker**, the engine rewrite: a historical map engine and a "do-everything" admin for any city. It brings the public viewer, the admin with its Setup Assistant and no-terminal install, the backend, the USGS and Landsat imagery pipeline with the georeferencer and joins, the import of local map archives (overview stitching included), the start page, stories, roles and review, many cities in one project, the static export and the local worker. Example: [București dispărut](https://bucurestiul-disparut.web.app/), the first map made with it.

This is a **pre-release**. The engine's contract may still change before v1.0.0. jsDelivr serves it only at this exact version (no `@1` line resolves to it), and `create-historic-city` will be published to npm under the dist-tag `beta`. The full notes are in [docs/releases/v1.0.0-beta.1.md](https://github.com/ventura8/historic-city-map-maker/blob/v1.0.0-beta.1/docs/releases/v1.0.0-beta.1.md), and the public contract is in [docs/ENGINE_API.md](https://github.com/ventura8/historic-city-map-maker/blob/v1.0.0-beta.1/docs/ENGINE_API.md).

## New in the last days

- **Viewer**: a compass, a timeline you can scrub with a live year chip, a date menu for a year with several dates, photo versions with zoom, and a map menu with Street View.
- **Games consoles and TVs**: the viewer works with a gamepad on PlayStation and Xbox browsers.
- **Admin**: a tile-import wizard with automatic stitching, and a georeferencer whose panes turn and whose approved points can be edited.
- **Your computers**: one governor shares the owner's computer politely, and the worker updates itself.
- **Analytics**: with consent, the wizards show where people stop.
- **Faster and cheaper**: the viewer paints before the map library arrives, and the pipeline and the cloud jobs use less memory.

## Start a city

- **Static, no backend**: copy the starter kit (`templates/starter-kit/`: `index.html`, `city.json`, `README.md`), edit `city.json`, put your Mapbox public token in it and publish the folder on any static host.
- **From a browser**: the start page creates your own Google Cloud project with the map and its admin, then hands over to the Setup Assistant.
- **From an existing city**: the admin's Export the city downloads a zip that serves the city from any static host.
